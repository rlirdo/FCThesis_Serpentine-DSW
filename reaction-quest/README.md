# 蛇紋石改質反應探險（Serpentine Reaction Quest）v2.1.1

大學程度的手機 **WebAR 全像闖關**教學遊戲。內容取自《從零基礎到論文實驗：化學整合教學簡報》
第 24–50 頁（第三階「認識論文的主角」、第四階「看懂論文的反應式」），
把論文的**五個主角**與**八式反應鏈**做成可以走、可以掃、可以答的關卡。

- 製作：游豐兆 博士生｜指導教授：楊悠娟 教授
- 國立東華大學自然資源與環境學系　仿生與環境工作坊
- 全部角色、場景、卡片、圖表、**音樂與音效**皆為本專案自製，**零版權素材**

### v2.1.1：選角卡改為純 CSS 驅動（2026/09/03）

v2.1 的選角卡把主色寫成 inline style，切換時要靠 JS 記得還原舊選取者；
而且四個「身分屬性」（背景、邊框色、放大、不透明度）都掛在 150 ms 的 CSS transition 上。
在**動畫時鐘被凍結**的環境（背景分頁、螢幕截圖服務）裡，
`document.timeline.currentTime` 停在 0、transition 永遠 `running` 且 `currentTime = 0`，
於是 `getComputedStyle` 會一直回傳「過渡前」的值——看起來就像選取態沒有跟著移動
（實際上 inline style 有正確更新，只是讀不到）。

v2.1.1 的作法：

- 主色改用 CSS 變數 `--sel`（選取底色）與 `--accent`（未選取邊框），在建卡時各設一次；
  切換時 JS **只加減 `.on`**，不再寫任何 inline style，也就沒有「要記得還原」這件事
- 身分屬性一律**不做過渡**，點下去的同一幀就是最終值；150 ms 的視覺過渡保留在金色外光暈（`box-shadow`）
- 未選取態明確寫 `transform:none`，避免留下 `matrix(1,0,0,1,0,0)` 之類的殘值

驗收（`tools/rq4_pick.js`，真 `pointerdown`／`pointerup`／`click`，點完立刻讀 `getComputedStyle`，
不做任何停用過渡的處理）：初始 ＋ 點 card1 → card2 → card0 共四次快照，
「選取者＝主色底＋3px 金框＋scale(1.04)＋opacity 1＋標籤可見、
其餘＝白底＋2px 主角色邊框＋opacity .85＋`transform:none`＋標籤隱藏、
三張卡皆無殘留 inline style、選取張數恆為 1」**四次全對**。

### v2.1 本機驗證數據

以 `tools/rq4_verify.js`／`rq4_sweep.js`／`rq4_cardmode.js`／`rq4_buttons.js` 在
375×812 與 414×896 兩種手機視窗實測（無相機降級路徑）：

- **音訊生命週期**：BGM 播放中 → 覆寫 `document.hidden=true` 並派送 `visibilitychange`＋`pagehide`
  → 1.5 秒後 `AudioContext.state === 'suspended'`、`AUDIO.current() === null`、
  存活振盪器 **0**、存活 interval／timeout 皆 **0**；回到前景不自動續播；
  收到使用者手勢才恢復成 `running` 並續播原曲
- **過關 jingle**：`bgm('win',{once:true})` 播滿一輪 3.636 秒後自動停 → `AnalyserNode` RMS **0**、振盪器 0，
  接著切下一關 `explore` 正常出聲（RMS 0.0083）
- **全破**：`allclear` 音效＋`win` 一輪後，RMS 於 **2.755 秒**歸零並持續到 6 秒（要求 3 秒）
- **防重疊**：3 位主角 × 10 關 × 收集／教學兩階段 × 375×812／414×896
  ＝ **120 組版面，投影矩形相交面積全部為 0**；卡片模式（假錨點，卡片約占畫面 66% 寬）
  亦為 0。主角投影高度：螢幕懸浮 18.91–19.77%（收集）／20.93–21.92%（教學）
- **答錯救援**：`RQ.answer(false)` → phase `wrong`、`#btn-retry` 顯示（150×52、hit-test 命中 DOM 按鈕而非 a-canvas）；
  `RQ.retry()` → 回到 phase `quiz`、熱區重新註冊、`retry` 音效觸發；
  連錯兩次 → `#btn-tip`＋`#btn-lvtop` 一起出現；答對 → 全部收起、`#btn-next` 出現
- **全流程**：基礎 5 關與進階 10 關各走完一次，抵達 `finish`、徽章顯示，
  **零 JS 錯誤、零警告**；邊界夾持 |x|,|z| ≤ 0.42；與 D-pad／動作鈕相交面積 0

> `tools/rq4_*.js` 皆為驗證腳本，不會被頁面載入；
> 驗證用的 `rq4_test.html` 腳手架（MessageChannel 時鐘＋可控 `document.hidden`）僅存在於本機，不進版。

## v2.0：卡片即舞台（架構級重做）

v1.x 是「走 2D 迷宮 → 到終點開相機掃一次卡 → 回到 2D 教學頁與問答頁」。
v2.0 拿掉迷宮，**從按下「開始冒險」到全破結算，背景永遠是相機實景，
所有內容都是懸浮 3D**，而且優先「站在卡片上」。

| 項目 | v1.1 | v2.0 |
|---|---|---|
| 場地 | 2D 格狀迷宮，方向鍵一步一格 | **卡片即舞台**：卡面就是棋盤，D-pad 讓主角在卡面上**平滑滑行（lerp）**，15–30 秒收集三個漂浮代幣 |
| AR | 只在終點掃描一次，掃完就離開相機 | **整關持續追蹤萬用卡／本關卡**；主角、代幣、對話看板、關鍵物件、反應動畫、題目全部掛在 `mindar-image-target` 錨點下懸浮 |
| 掉追蹤 | 掃不到就卡住 | `targetLost` **不中斷遊戲**：內容 300 ms 淡出／淡入轉為螢幕懸浮（`#rq-free`），`targetFound` 再自動回錨，**進度與狀態永不重置** |
| 文字頁 | 教學頁、問答頁、總結頁都是 2D 網頁 | **不再有任何 2D 文字頁**：全部是面向鏡頭的懸浮看板（canvas 貼圖，中文正常） |
| 音訊 | 無 | **五段 BGM ＋ 七個音效，全部 Web Audio 振盪器即時合成**（0 KB、零版權、真無縫循環）；iOS 在「開始冒險」手勢內解鎖 AudioContext |
| 關卡 | 6 關／12 關 | **基礎版 5 關（1、3、5、8、12）／進階版 10 關（1、3、5、6、7、8、9、10、11、12）** |
| 視差 | 無 | Android 直接用 `deviceorientation`；iOS 在手勢內 `requestPermission()`，拒絕則退回觸控拖曳視差 |
| 無相機 | 圖片模式（離開 AR） | **降級不離開懸浮**：背景換成該關花蓮場景 SVG，其餘玩法一模一樣，可以玩到全破 |

### 架構（`js/stage.js`）

```
單一 <a-scene>（整場只建一次，不隨關卡重建）
  ├─ <a-camera>              MindAR 只改投影矩陣，相機本體永遠在原點
  ├─ #rq-a0  targetIndex 0   本關專屬關鍵圖片
  ├─ #rq-a1  targetIndex 1   萬用卡（12 個 .mind 都內含，未重新編譯）
  ├─ #rq-free                螢幕空間懸浮（fallback）＋陀螺儀視差
  └─ #rq-holder
       ├─ #rq-ui             看板與題目（永不隨棋盤傾斜）
       └─ #rq-stage          主角、代幣、關鍵物件、平台、粒子
```

`#rq-stage` 與 `#rq-ui` 的 `object3D` 在 `#rq-a0`／`#rq-a1`／`#rq-free` 之間搬家
（`Object3D.add` 會自動從舊父節點移除 → 不會有第二份實例；DOM 完全不動 →
A-Frame 元件不會重新初始化 → 遊戲狀態永不重置）。

**換關不重建場景**：`STAGE.retarget()` 只把 MindAR 的 controller 換掉、重掛新的 `.mind`
（`sys.controller.dispose()` → `sys.imageTargetSrc = 新路徑` → `sys._startAR()`），
a-scene 與相機串流全程只有一份、一條。

**近平面校正（`syncFreeRig`）**：MindAR 的世界單位是目標圖片的像素，它會把相機
`near` 設成 10、`fov` 設成相機實際視角。螢幕懸浮群組因此不能放在 z = −1.30，
必須依 `near` 推距離、再依 `fov` 反推縮放，才能保持投影後的螢幕尺寸不變。

**相機邏輯完全沿用 v1.1 的 `js/ar.js`**（`acquireCamera()` 手勢內單一串流、
LINE `openExternalBrowser` 逃生、`probe()` 亮度健康檢查、一鍵診斷面板），一行未改。

### 音訊（`js/audio.js`）

即時合成，沒有任何音檔：

- **BGM ×5**：探索（輕快 D 大調五聲）／掃描（懸疑半音下行）／教學（沉靜長音）／問答（緊張脈動）／過關（歡慶大三和弦）
- **SFX ×7**：`coin` 代幣收集、`unlock` 三代幣集齊、`scanok` 舞台展開／掃描成功、`right` 答對、`wrong` 答錯、`clear` 過關、`allclear` 全破
- 以 `AudioContext.currentTime` 做 60 ms 週期、200 ms 前瞻的排程，循環接點在取樣層級對齊 → 真無縫
- 右上角「♪」靜音，狀態存 `localStorage`（`rq_muted_v2`）

### 效能

單關 1,686–5,400 三角形、31 個 mesh、粒子上限 200、貼圖 ≤1024、`pixelRatio` 夾 1.5、
不開陰影與後處理。持續追蹤較耗電，HUD 的「⚡」是**省電模式**（停止逐幀辨識、內容轉螢幕懸浮），預設關閉。

### 本機驗證（`tools/rq3_verify.js`、`tools/rq3_camtest.js`）

`rq3_verify.js`：無相機降級下走完基礎 5 關與進階 10 關，檢查零 JS 錯誤、代幣碰撞收集、
邊界夾持、遮蔽（主角與代幣的螢幕矩形對 D-pad／動作鈕零相交）、音訊狀態、
以及 `targetFound`／`targetLost` 交替 5 次時物件數與狀態不變。
`rq3_camtest.js`：用 `canvas.captureStream()` 假造一條真的 `MediaStream`，
讓 MindAR 走完整條路，驗證單一串流、影片不暫停、畫面亮度不歸零、換關 `retarget` 正常。

## 一句話玩法（給大學生）

> 把**萬用卡**平放在桌上、用手機對著它——主角就會站到卡片上；
> 用方向鍵讓他在卡面上滑行，碰到三個漂浮代幣就收集，集滿三個本關的關鍵物件會從卡片升起來，
> 看完懸浮教學再點答兩題就過關。卡片離開畫面也不會中斷，內容會自動改成螢幕懸浮，
> 把卡片放回來就回到全像模式。

## 綠色化學八條原則（v2.0 的去向）

v1.x 用「踩到陷阱格退回起點」把綠色化學原則藏進懲罰。v2.0 拿掉迷宮之後，
這八條原則的文案**完整保留在 `js/data.js` 的 `GAME_DATA.TRAPS`**，
並改由關卡教學看板與問答解析承載（第 5、8、9、11 關的解析都直接引用）：

| 原則 | 本研究的做法 |
|---|---|
| 第 6 原則：提高能源效率 | 25°C 常壓、40 kHz 超音波，不需要 800°C 高溫爐 |
| 第 5 原則：較安全的溶劑 | 全程以水為唯一介質、零有機溶劑 |
| 第 12 原則：本質安全防意外 | 常溫常壓操作，不用高壓反應釜 |
| 第 9 原則：以觸媒取代計量試劑 | Fe³⁺ 只用 0.05 wt%（約 9 mM），且是低毒的鐵 |
| 第 8 原則：減少不必要的衍生物 | 不使用保護基／脫保護，表面 –OH 直接是反應位點 |
| 第 1 原則：預防廢棄物優於末端處理 | 水相廢流在設計階段就規劃 |
| 第 11 原則：即時分析防污染 | 滴定全程監測並記錄 pH |
| 製程紀律 | TPGS 稀釋液只能緩慢倒轉十次；DSW 必須用滴管「滴」不是「倒」 |

## 學術誠實：哪些是假說

第 8 關（第四式　Fe³⁺ 與表面 –OH 形成內圈錯合物）、第 9 關（第五式　Mg²⁺ 補進晶格缺陷），
以及「遠紅外線放射率由 0.86 提升至 **0.93**」的目標，一律標示 **研究假說（待驗證）**：
關卡卡片右上角有金色標籤、教學面板有假說標籤、全破總結頁的反應鏈用金色底標出，
並在最後附上「哪些已證、哪些是假說」的對照說明。0.86 是已完成量測的原礦基線，0.93 是目標。
