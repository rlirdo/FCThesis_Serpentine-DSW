# 蛇紋石改質反應探險（Serpentine Reaction Quest）v1.1

大學程度的手機 **WebAR 迷宮闖關**教學遊戲。內容取自《從零基礎到論文實驗：化學整合教學簡報》
第 24–50 頁（第三階「認識論文的主角」、第四階「看懂論文的反應式」），
把論文的**五個主角**與**八式反應鏈**做成十二關可以走、可以掃、可以答的關卡。

- 製作：游豐兆 博士生｜指導教授：楊悠娟 教授
- 國立東華大學自然資源與環境學系　仿生與環境工作坊
- 全部角色、場景、卡片、圖表皆為本專案自繪，**零版權素材**

## v1.1 更新（四項體驗升級）

| 項目 | v1.0 | v1.1 |
|---|---|---|
| 迷宮主角 | 平面 SVG，轉向只能左右鏡射 | **A-Frame 程序化 3D 角色**（`js/char3d.js`）：Y 軸旋轉面向行進方向、行走上下起伏＋左右擺、待機呼吸縮放；選角畫面也是會自轉的 3D 預覽 |
| 移動手感 | 一按走一整格，轉角常常卡住 | **次格步進**：一次點按走 **1/3 格**（按住每 180 ms 一步），加上**預轉向緩衝**與**格心吸附**——路口前先按方向，走到路口就自動轉彎並對齊中心 |
| 每關兩題 | ABCD 文字選擇題 | **AR 互動題 ＋ 動畫影片題**（`js/quiz.js`＋`js/quizdata.js`＋`js/anims.js`）：點選 3D 物件、拖曳離子到正確位置、看 6–10 秒反應動畫後點出關鍵時刻／關鍵段落、步驟卡拖曳排序 |
| 卡片文字 | 字級寫死，`④Fe³⁺` 撐出圓外、`L00` 與說明文字重疊 | **逐字級量測縮排**（`PIL.ImageDraw.textbbox`）＋**程式化斷言**：任一文字不超出所屬形狀（含 ≥6% 內距）、任兩段文字 bbox 不相交；另出 bbox 檢查圖 |

**3D 角色的效能紀律**：單角色 < 1,600 三角形（球體 10×7 段、圓柱 8 段）、不開陰影與後處理、
`pixelRatio` 夾在 1.5，且**探索模式與掃描模式的 a-scene 絕不同時存在**（進掃描時 `CHAR3D.destroy()`，
回到迷宮時 `mount()` 重建），WebGL context 永遠只有一個。

**動畫是頁內自繪，不是影片檔**：本機沒有 ffmpeg（`where ffmpeg` 為空），
十段反應動畫一律以 Canvas 逐幀繪製（`draw(ctx, p)` 為純函式，所以進度條可任意拖曳、重播，
畫面永遠一致、可重現）。日後若安裝 ffmpeg，只要把 `draw` 逐幀輸出即可轉成真影片，介面不必改。

**免卡也能作答**：互動題一律在 `#quiz-stage` 裡建立自己的浮動 3D 場景，與掃描與否無關，
所以「掃描卡片」「免卡體驗」「跳過直接答題」三條路徑都能完整作答。

## 一句話玩法（給大學生）

> 用方向鍵在礦物迷宮裡走（**一按走 1/3 格**，按住連續慢走，轉角會自動幫你轉），
> 先撿齊三個試劑／條件代幣，終點才會解鎖；別踩到高溫爐與有機溶劑（違反綠色化學會被踢回起點），
> 走到終點掃卡片看 3D 反應式，再作答**兩題互動題**（一題點／拖 3D 物件、一題看動畫點關鍵時刻）就過關。

### 迷宮的可解性是被程式驗證過的

`js/maze.js` 生成迷宮時，陷阱只會放在「起點→終點」與「起點→各代幣」最短路徑聯集**之外**的格子，
因此一定存在一條完全不踩陷阱、可蒐齊三代幣並抵達終點的路線；`MAZE.verify()` 再用 BFS（避開陷阱）
實際確認一次。同一個 seed 永遠產生同一張圖，所以每一關都可重現、可驗證、可以練到熟。

## 陷阱格＝把教學藏進懲罰

踩到就退回起點（代幣保留），並跳出一句原則說明：

| 陷阱 | 說的是哪一條 |
|---|---|
| 🔥 800°C 高溫爐 | 綠色化學第 6 原則：提高能源效率（本研究 25°C 常壓） |
| 🧪 有機溶劑桶 | 第 5 原則：較安全的溶劑（本研究以水為唯一介質） |
| 💥 高壓反應釜 | 第 12 原則：本質安全防意外 |
| ☠️ 重金屬計量試劑 | 第 9 原則：以觸媒取代計量試劑（Fe³⁺ 只用 0.05 wt%） |
| 🔒 保護基工作台 | 第 8 原則：減少不必要的衍生物 |
| 🛢️ 廢液暫存槽 | 第 1 原則：預防廢棄物優於末端處理 |
| 🌀 劇烈震盪器 | 製程紀律：TPGS 只能緩慢倒轉十次 |
| 🥤 整瓶倒入區 | 製程紀律：DSW 必須用滴管「滴」不是「倒」 |

## 學術誠實：哪些是假說

第 8 關（第四式　Fe³⁺ 與表面 –OH 形成內圈錯合物）、第 9 關（第五式　Mg²⁺ 補進晶格缺陷），
以及「遠紅外線放射率由 0.86 提升至 **0.93**」的目標，一律標示 **研究假說（待驗證）**：
關卡卡片右上角有金色標籤、教學面板有假說標籤、全破總結頁的反應鏈用金色底標出，
並在最後附上「哪些已證、哪些是假說」的對照說明。0.86 是已完成量測的原礦基線，0.93 是目標。

## 重新產生素材

```bash
# 場景（12 張 SVG）
PYTHONUTF8=1 python tools/gen_scenes.py

# 關卡卡片 ＋ 萬用卡（1200×1200 @300dpi PNG）
PYTHONUTF8=1 python tools/gen_key_images.py

# A4 列印稿 PDF
PYTHONUTF8=1 python tools/gen_print_pdf.py

# .mind 目標檔（本機無 node，改用瀏覽器端離線編譯）
PYTHONUTF8=1 python tools/devserver.py 8766
#   → 瀏覽器開 http://localhost:8766/tools/compile-each.html
#   → 逐關編譯並 POST 回 targets/levelNN.mind，畫面會列出特徵點數
```

> `tools/compile-each.html` 開頭把 `requestAnimationFrame`／短 `setTimeout` 改接
> `MessageChannel`，因為 MindAR 的 Compiler 每個尺度層都 `await rAF`，分頁一旦不可見就會卡死。
